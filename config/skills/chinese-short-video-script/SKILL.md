# 中文短视频口播文案规范

## 1. 字数预算（硬性）

**每镜旁白字数 = 镜头秒数 × 4.5**（中文 TTS 语速约 4.5 字/秒）

| 镜头时长 | 旁白字数 |
| --- | --- |
| 3s | 13~14 字 |
| 4s | 18 字 |
| 5s | 22~23 字 |

超出会导致配音比画面长，下游只能截断或拉升，节奏全乱。
每行旁白控制在 **25 字以内**，超过就分行或拆镜。
**台词（人物对白）同一口径**：每句 6~18 字，一镜 1~3 句，
一镜台词字数之和也要满足「秒数 × 4.5」——对白挤不下就拆镜，
不要把两句拼成一句长句。

## 2. 结构：钩子-展开-收尾

- **第 1 镜（前 3 秒）必须有钩子**：反常识、强提问、具体数字、或直接给结论。
  例：`秋天的银杏，只美七天。` / `你家楼下的桂花，其实能做成糖。`
- **中段**：每镜推进一个新信息，不重复上一镜
- **末镜**：一句可被记住 / 可被评论的话（不喊"点赞关注"）

## 3. TTS 友好写法（重要）

IndexTTS / edge-tts 直接照字面读，以下写法会念错或卡顿：

| 不要写 | 原因 | 改成 |
| --- | --- | --- |
| `2024/10/31`、`10:30` | 斜杠与冒号读法不稳定 | `十月三十一号`、`十点半` |
| `3.5%` | 符号读不出 | `百分之三点五` |
| `AI`、`CPU`、`OK` | 英文词读法漂移 | 首次出现写中文：`人工智能`；确需保留就整句口语化 |
| `「」`《》 套嵌 | 停顿异常、吞字 | 用逗号句号断开 |
| `……`、连续感叹号 | 停顿过长 | 单个句号或逗号 |
| 长括号补充 `（其实……）` | 插入语节奏断裂 | 拆成独立短句 |
| 生僻成语堆叠 | 断句错误 | 换成口语同义表达 |

标点使用：只用 `，。？！`。**每隔 8~12 字必有一个逗号或句号**，
否则 TTS 找不到换气点。

## 4. 口语化三原则

1. **用动词不用形容词**：`把落叶夹进书里` ✅ / `很有秋天的感觉` ❌
2. **一句话一个信息点**，不写复合长句
3. **允许口语词**：`其实`、`真的`、`你看`、`结果`——但每镜最多一个语气词

## 5. 与分镜的分工

- `script.md` 的 `台词`：**人听的**，写清是谁说的——`- 台词：玉皇大帝：你们这届凡人，有点意思。`
  没人说话的镜头才写 `- 台词：旁白：……`
- `script.md` 的 `旁白`：过渡/补充信息，口语、有节奏
- `script.md` 的 `画面`：**机器看的**，具体可视化的名词 + 动作
  （分镜师会据此写 image_prompt，所以不要写情绪、隐喻、内心活动）

反例：`画面：她陷入了回忆，心里五味杂陈`
正例：`画面：她坐在窗边，手里捏着一张旧车票，杯中咖啡已经凉了`

## 6. 对白：让人物说人话

有人物出镜时，**优先写对白，不要把人的话压成旁白**——旁白没有角色
声线、嘴也不会动，成片就是「人物不说话，只有旁白」。

写法：

```markdown
### 镜头 2
- 台词：玉皇大帝：你们这届凡人，有点意思。
- 台词：老者：陛下，人间已经变天了。
- 画面：大殿上，两人隔桌对坐，烛火摇动
```

规矩：

1. 台词必须带角色名，且角色名与 `## 角色` 里的写法**逐字一致**
   （分镜师靠这个名字把台词挂到角色 id 上）。
2. 一句话一个意思，不写书面语长句（`然而，鉴于当前形势……` ❌）。
3. 人物的身份/职业/时代决定用词：古装角色不说「项目」、现代角色不说「朕」。
4. 同一镜里超过两个说话人时拆镜（LTX 多人同框容易崩，逐句也更清楚）。
5. 念不准的专有名词（数字、英文缩写）换成口语读法，同第 3 节。

## 7. 交付前自检

- [ ] 第 1 镜有钩子，且总长 ≤ 3 秒？
- [ ] 每镜台词/旁白字数 ≈ 秒数 × 4.5？
- [ ] 有人物出镜的镜头写了 `- 台词：角色名：…`（而不是全片旁白）？
- [ ] 台词里的角色名与 `## 角色` 一致、单句 ≤ 18 字？
- [ ] 旁白总字数 ≈ 总时长 × 4.5？
- [ ] 只用 `，。？！`，无数字符号/英文缩写/括号补充？
- [ ] 画面描述全部可视化，无情绪词？
- [ ] 镜头时长之和 = requirement.json 的 `duration_seconds`？
