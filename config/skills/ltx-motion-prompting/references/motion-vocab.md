# LTX-Video 运动词表

## 镜头运动（安全）

| 英文 | 说明 | 强度 |
| --- | --- | --- |
| `static shot` | 完全固定 | 最低（最稳） |
| `subtle drift` | 极轻微漂移 | 低 |
| `slow zoom in` | 缓慢推近 | 低 |
| `slow zoom out` | 缓慢拉远 | 低 |
| `gentle pan left` / `gentle pan right` | 缓慢横摇 | 低 |
| `slow tilt up` / `slow tilt down` | 缓慢俯仰 | 低 |
| `slow dolly forward` | 缓慢前移 | 中低 |
| `soft handheld sway` | 轻微手持感 | 中低 |
| `slow orbit around the subject` | 缓慢环绕 | 中（需首帧为单主体） |

## 镜头运动（谨慎 / 避免）

`fast zoom`、`rapid pan`、`whip pan`、`camera shake`、`handheld running`、
`dutch roll`、`360 rotation`、`zoom blur`

## 人物微动（安全）

`gently blinks`、`slowly breathes`、`slight smile forms`、`hair sways slightly`、
`turns head slightly`（≤15°）、`lowers eyes`、`shoulders relax`

## 人物动作（危险）

`walks`、`runs`、`jumps`、`dances`、`waves hand`、`points finger`、
`turns around`、`sits down`、`stands up`、`hugs someone`、`lifts the child`

> 需要位移时用**镜头运动**表达，不要用人物运动。

## 环境运动（安全，强烈推荐）

`leaves fall slowly`、`dust motes drifting`、`steam rises slowly`、
`smoke drifts`、`rain falls gently`、`water ripples`、`curtain sways slightly`、
`grass sways in the wind`、`clouds drift slowly`、`flickering neon light`、
`candle flame flickers`、`light sweeps across the surface`

## 动物（本项目常出现）

安全：`tail sways slowly`、`ears twitch`、`tilts head slightly`、`blinks slowly`、
`fur ruffles in the wind`、`chews slowly`
危险：`runs on the road`、`jumps up`、`shakes off water`、`spins around`

## 组合模板

```
# 空镜 / 风景
slow zoom out, clouds drift slowly over the ridge, grass sways in the wind

# 单人近景
slow zoom in, the woman gently blinks, dust motes drifting in the light

# 静物
static shot, steam rises from the mug, candle flame flickers

# 动物拟人
subtle drift, the husky tilts its head slightly, tail sways slowly, paper
sheets flutter in the wind
```
