# 抖音发布规范

## 1. 工具调用（唯一入口）

只调用一个工具：`publish video_path / title / tags`

- `video_path`：`final/final.mp4`（相对工作目录，不要写绝对路径）
- `title`：≤ 30 字（含标点），超出会被平台截断
- `tags`：**逗号分隔的纯词**，不要带 `#`（工具会自动去掉），3~5 个

只调用**一次**。不要为了"确认"重复调用——每次调用都会往
`.douyin/state.json` 追加一条发布记录。

## 2. 标题写法

| 要素 | 建议 |
| --- | --- |
| 长度 | 15~25 字最佳（≤30 字硬上限） |
| 句式 | 具体场景/结果 + 一个情绪钩子：`银杏只美七天，我在公园捡了一整个秋天` |
| 数字 | 用阿拉伯数字更醒目：`3 个`、`7 天` |
| 地点 | 有明确地域时前置：`沈阳街头的哈士奇补路工` |
| 禁止 | `点赞关注`、`转发抽奖`、纯堆词 `#秋天 #治愈 #风景` 塞进标题 |

**不要**在标题里写拍摄设备、模型名、`AI 生成` 之外的技术词；确需声明时写
`AI 生成` 四个字放句尾。

## 3. 标签（tags）

- 3~5 个，从"内容 → 品类 → 情绪/场景"三层各取一个
- 优先用平台上的常见话题词，不要自造生僻词
- 例：内容 `银杏` / 品类 `秋日风景` / 情绪 `治愈系` → `银杏,秋日风景,治愈系,城市漫步`

避免：与内容不符的蹭热点词、竞品名、平台名、`抖音` / `视频号` 等自身词。

## 4. 敏感词自查（发布前逐条过）

- 绝对化用语：`最`、`第一`、`唯一`、`顶级`、`永久`、`100%`
- 功效承诺：`治疗`、`治愈疾病`、`减肥`、`降血压`（"治愈系"是安全的情绪词）
- 金融诱导：`赚钱`、`稳赚`、`投资回报`
- 引流：`加微信`、`私信领取`、手机号、二维码、外链
- 危险模仿：危险动作未加提示、未成年人饮酒/驾驶
- 侵权：明星姓名/肖像、影视剧台词整段引用、他人品牌 logo

命中任一条 → 改写。**宁可平淡，不要被限流。**

## 5. 发布结果解读

`publish` 返回 JSON：

| 字段 | 含义 |
| --- | --- |
| `status` | `dry_run` = 未真实上传（`DOUYIN_DRY_RUN=true`）；`published` = 已上传 |
| `title` / `tags` | 实际提交的值（核对是否被截断） |
| `item_id` | 真实发布时返回的作品 id；dry-run 为 `null` |
| `published_at` | UTC 时间 |

汇报时**必须原样说明 status**，不要把 `dry_run` 说成"已发布"。

## 6. 前置条件

- 质检报告 `report/quality_report.json` 的 `passed` 必须为 `true`；
  未通过时不要发布，先汇报失败的检查项
- 成片 `final/final.mp4` 必须存在且非空

## 7. 自检

- [ ] 标题 ≤ 30 字、无绝对化用语、无引流？
- [ ] tags 3~5 个、逗号分隔、不带 `#`？
- [ ] 只调用了一次 `publish`？
- [ ] 汇报里 status 与实际一致（dry_run 就说 dry_run）？
- [ ] 质检 passed 为 true 才发布？
